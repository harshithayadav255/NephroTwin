# 20-minute demonstration video plan

Record a real run of the prototype. Do not claim that the synthetic index is a validated clinical predictor.

- 0:00–2:00 — Team, project title, problem, target population, scope boundary.
- 2:00–5:00 — Why heat-associated physiological strain in CKD is worth exploring; intended users and limitations.
- 5:00–8:00 — Architecture: historical profile + hourly stream → state/index → scenario simulator → dashboard.
- 8:00–11:00 — Explain synthetic data generation and fields; clearly distinguish simulated from measured.
- 11:00–14:00 — Run the app and explore patient profile and observed time series.
- 14:00–17:00 — Change hypothetical temperature/activity/hydration controls and explain the changed scenario trajectory.
- 17:00–19:00 — Tests, reproducibility, known limitations, and how real validation would be performed.
- 19:00–20:30 — Healthcare impact, responsible use, roadmap, repository walkthrough.

Before recording: show the app launching from the terminal, ensure charts render, and verify that all repository files open.
